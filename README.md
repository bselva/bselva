### What I believe about AI
 
AI doesn't change which problems matter. It changes how fast and how well we solve them. Agents are moving software from answering questions to finishing work, and the hard part is coordinating that work safely across people, agents and systems.
 
### How I build products
 
1. **Start with the problem.** Who is struggling, and what does it cost them?
2. **Set the goal.** What will be true when we've won?
3. **Validate the hypothesis.** What's the cheapest way to find out we're wrong?
4. **Focus on the one thing.** If we could do only one thing, what would it be?
5. **Scale through autonomy and clear goals.** Can every team decide without me?
